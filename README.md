# EVA Timer

[Open the timer](https://fuji400.github.io/eva-pomodoro/)

The original EVA activity-limit timer, with its rainbow frame, fonts, controls and sounds. Portrait keeps INTERNAL and EXTERNAL together below the countdown. Landscape gives most of the screen to the timer, with a compact readout strip below.

Choose 5:00, 10:00, 15:00 or 30:00. INTERNAL starts; EXTERNAL pauses. Open SETUP for a custom duration, SOUND and MOTION. Those preferences stay saved in the browser.

Original build: `fuji400/magi-clock-redesign`, `hud/`, commit `03c8068831d041f6e64e662de5e72cde0f12b5c4`. The original runtime, audio, fonts and base CSS are unchanged except asset URL relocation. Separate layout CSS and a small Setup integration provide the mobile layout and preference controls. This repository contains the static website served by GitHub Pages.
