# EVA Timer

[Open the timer](https://fuji400.github.io/eva-pomodoro/)

The original EVA activity-limit timer, with its rainbow frame, fonts, controls and sounds. A separate responsive stylesheet fixes phone spacing and clipped controls. Landscape fills the available screen; portrait groups the controls below the timer. Extremely short landscape screens prioritize the main timer over the secondary readouts.

Choose 5:00, 10:00, 15:00 or 30:00, or use SETUP. INTERNAL starts the timer; EXTERNAL pauses it. SOUND and MOTION use the original controls.

Original build: `fuji400/magi-clock-redesign`, `hud/`, commit `03c8068831d041f6e64e662de5e72cde0f12b5c4`. The original runtime, audio, fonts and base CSS are unchanged except for asset URL relocation. The HTML adds a responsive stylesheet and viewport safe-area support. This repository contains the static website served by GitHub Pages.
