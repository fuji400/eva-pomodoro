# EVA Pomodoro

[Open the timer](https://fuji400.github.io/eva-pomodoro/)

A standalone EVA-style Pomodoro timer. Choose Focus (25 minutes), Short break (5 minutes), or Long break (15 minutes), then START. STOP pauses; RESET returns to the selected duration; SETUP supports a custom duration.

Timing survives refresh in the same browser. Sound is off by default. SOUND ON previews the original EVA start effect and enables the start/zero effects. TEST SOUND previews it again; SOUND OFF stops playback immediately. Keep the tab open for timely sound; background browser suspension may delay it. After four focus sessions, choose a long break. Sessions start manually.

No account, analytics, or server connection. This repository contains the built static website served by GitHub Pages.
